## Entry

`main.py` (Python 3.13, stdlib only) writes one line of plain text — the
GPS's own excuse, in its own voice, for sending the driver down the wrong
road — to `$MAKEFUN_OUTPUT_DIR/entry.txt` (falling back to `/output/entry.txt`).

> The map swore that cul-de-sac cut through to the highway, so blame the cartographer — I merely delivered you to his unfinished business.

## Run

```sh
python3 main.py
```

Deterministic: every run writes the identical line.
